# Proyecto LUCYDAY con herencia

Proyecto Java Maven para abrir en Apache NetBeans 26. El código está en el paquete `lucyday`.

## Clases
- `Producto`: clase base con datos y operaciones comunes del inventario.
- `ProductoFacial`: subclase con tipo de piel e ingrediente activo.
- `ProductoCapilar`: subclase con tipo de cabello y beneficio.
- `Inventario`: administra productos usando el tipo general `Producto`.
- `Main`: menú para ejecutar el inventario y demostrar herencia y polimorfismo.

## Ejecutar
Abre la carpeta que contiene `pom.xml` con **File > Open Project**. La clase principal es `lucyday.Main`.
